# Proyecto de Perceptrones en Python

## Descripción

Proyecto desarrollado en Python como parte de la práctica de programación y algoritmos.

El programa implementa una red de **5 perceptrones**, utilizando programación orientada a objetos y sin librerías externas.

Cada perceptrón recibe dos entradas, realiza una suma ponderada utilizando sus pesos y determina una salida binaria (0 o 1) según un umbral de activación.

## Funcionamiento

- Se define una clase `Perceptron` con sus respectivos pesos, umbral y descripción.
- Se procesan entradas almacenadas en una matriz.
- Los perceptrones se conectan entre sí, utilizando las salidas de algunos como entradas de otros.
- Se analizan los resultados obtenidos mediante distintas funciones de procesamiento y búsqueda.

## Conceptos aplicados

- Programación orientada a objetos (POO).
- Clases, métodos y objetos.
- Matrices y listas.
- Funciones y estructuras de control.
- Procesamiento de datos.
- Lógica de perceptrones y funciones de activación.

## Tecnologías

- **Lenguaje:** Python 3
- **Librerías externas:** Ninguna

## Objetivo

Comprender el funcionamiento básico de una red de perceptrones y aplicar conceptos de programación para resolver problemas mediante el procesamiento de entradas y salidas binarias.
