# 🐍 Proyectos en Python

Repositorio donde recopilo proyectos desarrollados durante mi aprendizaje
de Python y mi formación en Ingeniería en Sistemas de Información.

Estos proyectos están enfocados en la resolución de problemas, programación
estructurada, modularización y manejo de datos.

## 📂 Proyectos

### 🎫 Gestor de Tickets
Sistema desarrollado en Python para registrar y procesar tickets,
aplicando estructuras de datos, funciones, búsquedas y procesamiento
de información.

### 🛠️ Gestor de Servicios
Programa para gestionar información relacionada con distintos servicios,
aplicando programación modular, validaciones y procesamiento de datos.

### 🔢 Constante de Kaprekar
Implementación del algoritmo de Kaprekar para números de cuatro dígitos,
realizando ordenamientos y operaciones sucesivas hasta alcanzar la
constante 6174.
