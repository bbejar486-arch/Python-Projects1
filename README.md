# 🐍 Python Projects

Repositorio donde recopilo proyectos y ejercicios desarrollados durante mi aprendizaje de **Python** y mi formación en **Ingeniería en Sistemas de Información**.

Los proyectos están enfocados en la resolución de problemas, el desarrollo del pensamiento lógico, la programación estructurada y orientada a objetos, la modularización y el procesamiento de datos.

## 📂 Proyectos

### 🎫 Gestor de Tickets

Sistema desarrollado en Python para registrar y procesar tickets, aplicando estructuras de datos, funciones, algoritmos de búsqueda y procesamiento de información.

### 🛠️ Gestor de Servicios

Programa para gestionar información relacionada con distintos servicios, aplicando programación modular, validaciones y procesamiento de datos.

### 🔢 Constante de Kaprekar

Implementación del algoritmo de Kaprekar para números de cuatro dígitos, realizando ordenamientos y operaciones sucesivas hasta alcanzar la constante **6174**.

### 🧠 Red de Perceptrones

Implementación de una red de cinco perceptrones utilizando programación orientada a objetos en Python, sin librerías externas.

El proyecto permite procesar una matriz de entradas binarias mediante perceptrones interconectados, donde las salidas de algunos se utilizan como entradas de otros.

**Conceptos aplicados:**
- Programación orientada a objetos.
- Clases, métodos y objetos.
- Matrices y listas.
- Operaciones con pesos y umbrales.
- Funciones de activación binaria.
- Procesamiento y análisis de resultados.

## 🛠️ Tecnologías

- **Python 3** — Lenguaje principal de programación.
- **Git** — Control de versiones.
- **GitHub** — Almacenamiento y documentación de proyectos.

Este repositorio tiene como objetivo documentar mi progreso en el aprendizaje de programación, consolidar conocimientos y mejorar mis habilidades en el diseño de algoritmos, estructuras de datos y resolución de problemas.
