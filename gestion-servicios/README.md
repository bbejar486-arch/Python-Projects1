
# 🛠️ Gestor de Servicios

Programa desarrollado en Python para cargar, organizar y procesar
información relacionada con servicios.

El objetivo del proyecto es aplicar conceptos de programación estructurada
para resolver un problema de gestión de datos.

## ⚙️ Funcionalidades

- Registro de servicios
- Validación de datos ingresados
- Procesamiento de información
- Búsqueda de registros
- Obtención de estadísticas

## 🧠 Conceptos aplicados

- Funciones
- Listas
- Ciclos
- Condicionales
- Validaciones
- Búsqueda y ordenamiento
- Modularización del código

## ▶️ Ejecución

Para ejecutar el programa:

```bash
python main.py
