# 🎫 Gestor de Tickets

Programa desarrollado en Python para registrar y procesar tickets.

El proyecto permite cargar información de distintos tickets y realizar
operaciones sobre los datos ingresados.

## ⚙️ Funcionalidades

- Carga de tickets
- Validación de datos
- Búsqueda y procesamiento de información
- Cálculo de estadísticas
- Organización de tickets según sus datos

## 🧠 Conceptos aplicados

- Funciones
- Listas
- Condicionales
- Ciclos
- Búsquedas
- Contadores y acumuladores
- Programación modular

Para ejecutar el programa:

```bash
python main.py
